# Gabriela Domenzain

Sitio personal estático: comunicación institucional, planeación estratégica y relaciones públicas.

- `index.html`: la página.
- `assets/site.css`: estilos.
- `assets/CV_Gabriela_Domenzain.pdf`: CV descargable.
- Para añadir una foto, guarda una imagen vertical como `assets/foto.jpg`.

## Versiones legibles por máquinas (LLMs, buscadores, ATS)

- `llms.txt`: resumen para modelos de lenguaje (estándar llmstxt.org), con resumen en inglés.
- `index.md`: el perfil completo en Markdown.
- `cv.json`: el CV en formato [JSON Resume](https://jsonresume.org/schema).
- `sitemap.xml`: mapa del sitio.
- `index.html` incluye datos estructurados schema.org (`Person` y `ProfilePage`) en JSON-LD.

Al actualizar el CV, actualiza también estos archivos para que digan lo mismo.
